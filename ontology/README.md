# BioNExt ontology

`bne_ontology.ttl` and `bne_ontology.owl` are version 1.0.0 of the BioNExt Ontology
(<https://w3id.org/bionext/ontology/>, version IRI
<https://w3id.org/bionext/releases/v1.0.0/bionext.ttl>). They are included unchanged so that
the tests and `scripts/generate_vocabulary.jl` can check the package against the exact release it
was generated from.

- Creator: <https://orcid.org/0009-0003-1344-2449>
- Publisher: S3Bio, <https://s3bio.gitlab.io/>

The MIT license in the repository root covers the package code, not these ontology files.
